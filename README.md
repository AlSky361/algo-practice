## Как это устроено

- `leetcode/NNNN-slug-name/` — задачи с LeetCode (алгоритмы)
- `deepml/NN-slug-name/` — задачи с DeepML
- `sql/NNNN-slug-name/` — задачи из раздела LeetCode Database

Внутри папки задачи:
- `solution.py` и/или `solution.cpp` — решение
- `meta.yml` — метаданные — **обязателен** для каждой папки задачи
